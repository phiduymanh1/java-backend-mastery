# Spring Boot

Tài liệu học Spring Boot được nhóm theo chủ đề.

## Cấu trúc hiện tại

```text
spring-boot/
├── README.md
└── spring-security/
    ├── README.md
    ├── DocumentSpringSecurity.md
    ├── DocumentJWT.md
    ├── DocumentResourceServer.md
    ├── DocumentOIDC.md
    ├── DocumentAuthorizationCodePKCE.md
    └── DocumentSpringAuthorizationServer.md
```

## Các nhóm tài liệu

| Nhóm | Nội dung |
| --- | --- |
| [Spring Security](spring-security/README.md) | Xác thực, phân quyền, JWT, Resource Server, OIDC, Authorization Code + PKCE, Spring Authorization Server và vòng đời token. |

Mỗi nhóm có README riêng để giới thiệu nội dung và hướng dẫn thứ tự đọc trong nhóm. Khi thêm nhóm mới, tạo thư mục cùng README của nhóm và bổ sung liên kết vào bảng trên.

Thư mục hiện có tài liệu học; chưa có module Java, `src/`, `pom.xml` hoặc `build.gradle`. Tài liệu mới cùng chủ đề được đặt trong thư mục tương ứng và cập nhật vào mục lục.
